### Deloitte Cybersecurity - Incident Response Investigation
**Focus:** Log analysis, threat detection, insider threat investigation, behavioral analytics  
**Completion:** January 2026  
**Platform:** Forage

Investigated suspected data breach at manufacturing client (Daikibo Industrials) following leak of sensitive production status information to media. Analyzed 190+ pages of web request logs spanning 72 hours to identify source of unauthorized data access. Identified compromised user account conducting automated data exfiltration via API polling at precise 60-minute intervals across 4 global manufacturing facilities.

**Key Skills:** Log analysis, pattern recognition, threat detection, incident response, behavioral analytics, attack vector analysis, MITRE ATT&CK mapping

**Key Findings:**
- Identified compromised user account through behavioral pattern analysis (machine-precise timing vs. human activity)
- Determined attack vector required internal VPN access (insider threat or credential compromise)
- Detected automation signatures: exact 60:00 intervals, missing page resources, simultaneous multi-factory queries
- Script persistence through session expiration (64 consecutive 401 errors over 15+ hours)

**Deliverables:**
- Comprehensive incident investigation report with evidence timeline
- Attack pattern analysis (normal vs. suspicious user behavior comparison)
- 15-point remediation strategy (immediate, short-term, long-term improvements)
- Security recommendations: session management, rate limiting, behavioral anomaly detection, UEBA implementation

- **Practical deliverables** for portfolio demonstration

These programs simulate authentic consulting and analyst work, including client documentation review, stakeholder communication, technical analysis, and professional reporting—core competencies for cybersecurity roles.
