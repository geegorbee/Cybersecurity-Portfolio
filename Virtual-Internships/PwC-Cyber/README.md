## Critical Findings Summary

### Access Control & IAM Gaps

- Shared credentials among teams (accountability failure)
- Informal access provisioning via phone requests
- Missing role-based access controls (RBAC)
- No formal user access request/approval workflow

### Segregation of Duties Violations

- Single users controlling complete transaction lifecycles
- Developer with implementer access (change management SoD conflict)
- Payment authorization and processing not separated

### Business Process Control Weaknesses

- Missing three-way match control (PO, receipt, invoice)
- No supplier due diligence or vendor validation
- Automated approvals without validation
- Insufficient cash reconciliation procedures

### IT General Controls (ITGC) Gaps

- Emergency changes bypassing approval requirements
- No design reviews before production deployment
- Undocumented configuration management procedures
