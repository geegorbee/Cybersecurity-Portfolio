# Active Directory Home Lab Project

Building hands-on Active Directory administration skills through structured learning and practical implementation.

-----

## Project Structure

### Phase 1: Windows Client Administration ✅ COMPLETE

Completed Microsoft MD-100 learning modules as foundation for Active Directory client-side administration:

- **Support the Windows client environment** - Group Policy, domain operations, client configuration
- **Configure networking on Windows clients** - TCP/IP, DNS, DHCP, network troubleshooting
- **Troubleshoot the Windows client operating system and apps** - Diagnostic tools, systematic troubleshooting, remediation workflows

**Microsoft Learn completion certificates:** 
https://learn.microsoft.com/en-us/training/modules/monitor-troubleshoot-windows-client-performance/8-summary#completion
https://learn.microsoft.com/en-us/training/modules/employ-remote-management/8-summary#completion


-----

### Phase 2: Active Directory Server Administration 🔨 IN PROGRESS

**Planned implementation:**

- Windows Server domain controller setup
- Active Directory domain services configuration
- Organizational Units (OUs) and security group structure
- User account provisioning and management
- Group Policy Objects (GPOs) for client configuration
- PowerShell automation for common AD tasks
- Authentication workflows and troubleshooting
